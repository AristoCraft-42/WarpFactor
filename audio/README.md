# Звуки и музыка

Пока своих файлов нет, всё звучит **синтезированными заглушками**: код в этой папке собирает их
при запуске игры (`placeholder_sounds.gd`, `placeholder_music.gd`). Свой файл с тем же именем
заменяет заглушку — остальное продолжает звучать как было.

## Звуки: `audio/sfx/<id>.ogg`

Формат — `.ogg` (лучше всего) или `.wav`; моно, 44100 или 22050 Гц. Громкость и разброс высоты
задаёт игра (`SFX_PARAMS` в `audio_director.gd`), так что файл можно делать «на полную».
Несколько вариантов одного звука — `shot.ogg`, `shot_2.ogg`, `shot_3.ogg`: игра выберет случайный.

| id | когда звучит |
|---|---|
| `ui_click` | нажатие любой кнопки |
| `ui_error` | предупреждение (жёлтое уведомление) |
| `ui_notify` | обычное уведомление |
| `ui_success` | (пока не используется) |
| `build` / `deconstruct` / `rotate` | игрок поставил, снёс, повернул здание |
| `building_destroyed` | здание разрушено врагами |
| `shot` / `shell` | выстрел пулей (турель, дрон) / артиллерией |
| `explosion` / `hit` | взрыв снаряда / попадание пули |
| `zap` / `repair` / `spray` | тесла-турель / ремонтная / жидкостная |
| `enemy_death` / `enemy_melee` / `enemy_shot` | гибель врага / удар / выстрел врага |
| `mine` | дрон добыл предмет |
| `crate` | подобран груз |
| `drone_destroyed` / `drone_respawn` | дрон сбит / появился снова |
| `wave_warning` / `wave_start` | предупреждение о волне / волна пошла |
| `research_done` | исследование завершено |
| `teleport` | начало телепортации |
| `factory_loop` | фон цеха — **петля**, громкость от числа работающих зданий на экране |

Звуки мира привязаны к месту: слышно то, что на экране и чуть за ним, с панорамой по положению.

## Музыка: `audio/music/<состояние>*.ogg`

Музыка следует за обстановкой. Состояния:

| состояние | когда |
|---|---|
| `menu` | главное меню |
| `calm` | спокойно: стройка, разведка |
| `tension` | идёт предупреждение о волне, волна появляется или враги где-то на планете |
| `combat` | враги на экране или рядом, атакуют постройки |

Файл называется с имени состояния: `calm.ogg`, `calm_night.ogg`, `combat_1.ogg`… Если у
состояния несколько файлов — играют по очереди в случайном порядке, переход между состояниями —
плавное затухание. Состояние без своих файлов звучит заглушкой: она сделана из четырёх слоёв
одной петли (пэд, мелодия, бас, ударные), которые включаются и гаснут по обстановке.

Для петли в Godot: выделить файл в FileSystem → вкладка Import → `Loop` → Reimport
(у `.ogg` и `.wav` это одна галочка).

## После добавления файлов

```
godot --headless --path D:\Mind --import
```

Громкость — в настройках, вкладка «Звук»: общая, музыка, эффекты, фон цеха.
