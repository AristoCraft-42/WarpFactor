    Враги и волны

    Враги идут к центральному шлюзу по полю потоков, по дороге бьют постройки и дрона в радиусе атаки и ломают постройки, перегородившие путь. Атака мгновенная, без снарядов. Из бюджета волны набираются враги по их стоимости угрозы.
