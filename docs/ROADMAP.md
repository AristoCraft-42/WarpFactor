# Flowworks — план разработки под GDD 0.1

Утверждён 2026-09-14. Заменяет прежний план этапов 5–8 из `ARCHITECTURE.md`.
Дизайн-документ: `docs/GDD.md`. Решения, принятые при обсуждении плана, — в разделе 6.

## 1. Что изменилось в целях

| Тема | Было | Стало |
|---|---|---|
| Жанр | Песочница без боя и проигрыша | Фабрика + выживание + оборона; Game Over по-прежнему нет |
| Структура игры | Кампания уровней с целями | Забег: постоянная база путешествует между одноразовыми планетами |
| Игрок | Свободная камера | Дрон: WASD, камера следует за ним, стройка в радиусе, может добывать руду |
| Хранение | Глобальный склад ядра | Ядра нет. Предметы лежат в складах и в инвентаре дрона (ячейки со стаками) |
| Стоимость построек | Списание ресурсов из ядра | Постройка — предмет: крафтится руками (очередь, как в Factorio), ставится из инвентаря |
| Прогресс | Пороги доставки и контракты уровня | Развитие базы: лаборатории (предметы + энергия), дерево исследований, расширения |
| Потеря | Нет | При телепорте теряется всё вне базы и вне площадки центрального шлюза |
| Давление | Нет | Угроза растёт со временем на планете, волны врагов |
| Бой | Запрещён | Прочность зданий, враги, турели, стены |
| Электричество | После всех этапов | Этап 11, до исследований (лабораториям нужна энергия) |
| Карты | Только ручные уровни + редактор | Генерация планет по типам |
| Песочница | Галочка при старте уровня | Творческий режим: постройки не расходуются, радиус не ограничен, угрозы нет |

## 2. Что остаётся из сделанного (этапы 1–4)

**Переносится без переписывания:**
- сетка, чанки, `BuildingManager`, размещение, поворот, выделение, копирование;
- тик симуляции, сон и пробуждение, ленты (SoA), логистика, буры, заводы, рецепты из данных;
- рендер: атласы, MultiMesh предметов, оверлеи, превью;
- формат `.fwmap`, меню, настройки, RU/EN, тесты.

**Переделывается:**
- `CoreStorage` и ядро уступают место `Inventory` у складов и у дрона;
- стоимость построек становится предметом-постройкой;
- `LevelDef` превращается в `PlanetDef`/`BaseDef`, `Game` — в забег с двумя мирами;
- камера следует за дроном.

**Отменяется:**
- цели уровней;
- разблокировки по порогам доставки;
- контракты на время;
- счётчик доставки в ядро и сжигание излишка.

## 3. Новая архитектура (крупными блоками)

**Предметы и постройки:**
- у каждой строящейся постройки есть свой `ItemType` (поле `building`);
- у `ItemType` есть размер стака;
- ручной рецепт постройки: ингредиенты из `BuildingDef.cost`, время `craft_time`, выход `craft_amount`;
- на лентах, в складах и инвентаре постройки — такие же предметы, как руда.

**Инвентарь (`Inventory`):**
- ячейки, в каждой один тип предмета до размера стака;
- кэш суммарного количества и свободного места делает проверку «влезет ли» O(1) — важно для складов, в которые грузят ленты.

**Дрон (`Drone`):**
- модель в тике симуляции с интерполяцией: позиция, инвентарь, радиус действий;
- добыча руды, очередь крафта (промежуточные детали докрафчиваются автоматически);
- все действия игрока в мире проверяют радиус.

**Забег (`Run`):**
- владеет миром базы, миром планеты, дроном, общими часами, угрозой, исследованиями и маршрутом;
- `Run.step()` прогоняет обе симуляции, передачу через шлюзы, угрозу и врагов в фиксированном порядке.

**Шлюзы — зеркальные пары:**
- центральный шлюз стоит в центре площадки на планете, его пара — в центре базы;
- предмет, вошедший в сторону шлюза, выходит с той же стороны пары; направление каждой стороны настраивается;
- дрон переходит между мирами, влетая в шлюз;
- переносной шлюз открывается исследованием, его пару игрок ставит в базе сам.

**Площадка центрального шлюза:**
- постоянная часть базы, переезжает при любой телепортации вместе с постройками и предметами;
- теряется только то, что уже разрушено;
- размер растёт исследованиями.

**Бой** — всё хранится как данные:
- `EnemySystem` (SoA, MultiMesh) и `FlowField` к шлюзу;
- `ThreatDirector` с кривой угрозы и волнами из `.tres`;
- турели на патронах через `Consume`.

**Сохранения:**
- бинарный файл из секций с версиями;
- каждая система пишет свою секцию.

**Цель по производительности:** 5000+ зданий суммарно и 1000 врагов при 60 FPS на ×1.

## 4. Этапы

Правила прежние:
- один этап за ответ, каждый — играбельная сборка;
- файлы на диск, в ответе список;
- после этапа — ручные проверки и ограничения;
- коммит на этап.

### Этап 5 — Дрон, инвентарь, склады, крафт (пока в одном мире) ✅
- Дрон: WASD, камера следует за ним, радиус стройки и взаимодействия, добыча руды с ЛКМ.
- Ядро и `CoreStorage` убираются. Контейнер и хранилище становятся складами с ячейками; разгрузчик берёт из складов.
- Постройки — предметы, стройка расходует их из инвентаря. Снос возвращает постройку и её содержимое.
- Ручной крафт: очередь со временем, автоматический докрафт промежуточных деталей, отмена с возвратом.
- Окно инвентаря и крафта. Окно постройки: содержимое склада или завода, перенос кликом. В меню стройки — количество в инвентаре и кнопка крафта.
- Творческий режим вместо песочницы.
- «Переливной/Обратный шлюз» переименовываются в «клапаны».
- **Проверка руками:** добыть руду дроном → скрафтить бур и ленты → бур → лента → склад → забрать из склада → скрафтить завод.

### Этап 6 — База и планета ✅
- `Run`: два мира тикают одновременно; `BaseDef` и `PlanetDef`.
- База 24×24, порта у шлюза два (вход в базу — запад, выход наружу — восток), вход дрона по F, площадка 15×15.
- Отдельный флаг «где можно ставить» не понадобился: в базе нет руды, буры туда не встают сами.
- Центральный шлюз и его пара в базе с зеркальными сторонами; дрон проходит через шлюз между мирами.
- Площадка вокруг шлюза на планете: граница, оверлей.
- `WorldView`: неактивный мир не рисуется, но симулируется.
- **Проверка руками:** добыча на планете → шлюз → пара в базе → завод в базе → склад базы.

### Этап 7 — Телепортация и забег
- Зарядка телепорта, экран итога «доставлено / потеряно».
- Переезд площадки: её постройки и предметы переносятся к шлюзу на новой планете.
- Простая генерация планет по сиду и типу: руды, рельеф, место посадки, точки появления врагов.
- Выбор следующей планеты из 2–3 вариантов, безопасные планеты.
- «Новый забег» в меню.
- **Проверка руками:** полный цикл «прилёт → добыча → телепорт → следующая планета», площадка переехала.

### Этап 8 — Сохранения
- Секции: забег, база, планета, площадка, дрон и инвентарь, очередь крафта, ленты, буферы.
- Автосейв при прибытии и перед телепортом, ручные слоты, «Продолжить» и «Загрузить».
- Тест детерминизма: сохранить → загрузить → N тиков → совпадение с непрерывным прогоном.

### Этап 9 — Угроза и враги
- Прочность зданий, урон, разрушение: без возврата, содержимое теряется.
- Кривая угрозы, волны из данных, предупреждения.
- Враги и поле потоков к шлюзу; враги ломают препятствия.
- Дрона могут сбить: возрождение у центрального шлюза.
- Прорыв (шлюз уничтожен) — аварийная телепортация; площадка переезжает, теряется разрушенное.
- Бенчмарк: 1000 врагов и 5000 зданий.

### Этап 10 — Оборона
- Турели на патронах с ленты, снаряды-данные, стены, ремонт.
- Оверлей радиусов, индикатор угрозы и следующей волны.
- **Проверка руками:** весь цикл из GDD §10 играбелен. Первый плейтест и настройка темпа.

### Этап Д — Дизайн ресурсов и производства (GDD §19, без кода)
- Совместная сессия по ощущениям от плейтеста.
- Результат — таблица ресурсов, планет, цепочек и рецептов.

### Этап 11 — Энергия
- Сеть: узлы, генераторы, `ConsumePower`, фаза `PowerGraphSystem`, оверлей.

### Этап 12 — Исследования
- Лаборатория — отдельная постройка, тратит предметы и энергию.
- Дерево из данных: зависимости, эффекты.
- Эффекты: постройки, переносной шлюз, стороны шлюза, площадка, расширения базы.
- Экран дерева.

### Этап 13 — Пространство базы
- Расширения базы, компактные версии зданий.
- Сборщики, которые крафтят постройки автоматически.
- Перенос групп зданий.

### Этап 14 — Контент
- Ресурсы, цепочки, типы планет и врагов по итогам этапа Д; баланс.

### Этап 15 — Планеты
- Полноценный генератор по типам планет, аномалии и безопасные зоны.

### Этап 16 — Эндгейм и полировка
- Строительство со временем (возможно, дронами), условие победы.
- Спрайты Aseprite, звук, UX, GDExtension для горячих систем по результатам бенчмарков.

## 5. Риски

1. **Две симуляции одновременно.** Держим сон и пробуждение, бенчмарк «база 3000 + планета 3000».
2. **Поле потоков на GDScript.** Пересчёт кусками на несколько тиков, иерархия по чанкам; запасной план — GDExtension.
3. **Враги и снаряды.** SoA и пространственная сетка; при нехватке — GDExtension.
4. **Рост сохранений.** Секции с версиями, тест детерминизма.
5. **Много TBD в GDD.** Системы делаем на данных, контент остаётся плейсхолдером до этапа Д.

## 6. Принятые решения (обсуждение 2026-09-14)

| Вопрос | Решение |
|---|---|
| Материалы для стройки | Постройки крафтятся из предметов в инвентаре дрона и ставятся из инвентаря |
| Хранение | Ядра нет; склады и инвентарь дрона с ограниченным числом ячеек |
| Инвентарь | Ячейки со стаками, как в Factorio |
| Ручной крафт | Очередь со временем, промежуточное докрафчивается само; переработка руды — только в заводах |
| Игрок | Дрон (WASD), стройка в радиусе; враги могут сбить, возрождение у шлюза |
| Добыча дроном | Да, медленно |
| Шлюзы | Центральный фиксированный (вход дрона в базу) и переносной (открывается исследованием); зеркальные пары |
| Где строить | Везде. За пределами площадки центрального шлюза всё теряется при телепорте |
| Прорыв | Площадка переезжает, как при обычной телепортации; теряется только разрушенное |
| Планеты | Генерация по типам |
| Исследования | Лаборатория — отдельная постройка, тратит предметы и электричество |
| Строительство | Пока мгновенное, со временем — в будущем |
| Клапаны | «Переливной/Обратный шлюз» переименовываются в «клапаны» |
