# WarpFactor

Фабрика, выживание и оборона мобильной базы: добыча, конвейеры, переработка, логистика, энергия,
исследования и оборона. Godot 4.7.2, GDScript. Дизайн — [docs/GDD.md](docs/GDD.md),
план — [docs/ROADMAP.md](docs/ROADMAP.md), архитектура — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md),
контент ранней игры — [docs/CONTENT.md](docs/CONTENT.md).

## Запуск

Откройте папку в Godot 4.7.2 и нажмите F5 (главное меню).
В меню «Новый забег» — первая планета генерируется по сиду.
F6 на `core/game.tscn` запускает готовую тестовую карту (`-- --level=rift` — другую), `-- --seed=123` — сгенерированный забег.

## Управление (по умолчанию, переназначается в настройках)

| Действие | Клавиши |
|---|---|
| Полёт дрона | WASD / стрелки (камера следует за дроном) |
| Спуститься на подземный этаж / подняться на площадку | F над центральным шлюзом (или его парой на этаже) и над лифтом. Этаж открывается исследованием «Подземный этаж» |
| Телепорт | Клик по шлюзу или паре: звёздная карта, выбор планеты, «Телепорт» (зарядка 30 с, можно отменить) |
| Поворот портов шлюза | R над шлюзом или парой (поворачиваются независимо) |
| Быстрое сохранение / загрузка | F5 / F9; слоты — в меню паузы, «Продолжить» и «Загрузить» — в главном меню |
| Подобрать выпавший груз | Подлететь к нему (после того как дрона сбили) |
| Оборона | Вкладка «Оборона»: каменная стена (линией) и пулемётная турель. Патроны (гильза + наполнитель) — лентой или руками: ЛКМ по турели, затем клик по патронам в инвентаре |
| Автопушка и ремонт дрона | Сами: пушка бьёт ближайшего врага, дрон бесплатно чинит повреждённые постройки в радиусе |
| Радиусы турелей | T (у турели в руке, под курсором и выбранной — всегда) |
| Осмотреться | СКМ с перетаскиванием; H — вернуть камеру к дрону |
| Зум | Колесо (к курсору), `=` / `-` |
| Добыча руды | ЛКМ по руде с зажатием (в радиусе дрона) |
| Инвентарь и крафт | E или Tab; рецепт: ЛКМ — 1, ПКМ — 5, Shift+ЛКМ — сколько хватит |
| Отмена крафта | Клик по группе в очереди внизу: ЛКМ — 1, ПКМ — 5, Shift+ЛКМ — все |
| Окно здания | ЛКМ пустой рукой по зданию: ячейки сырья, топлива и продукта, полоски прогресса, питания и жидкостей; ячейка здания: ЛКМ — забрать стопку, ПКМ — половину |
| Строить / линией | ЛКМ / ЛКМ с зажатием. Лента через препятствие ставит мостовой конвейер, через чужую ленту — перекрёсток (если они есть в инвентаре). Опоры ЛЭП протягиваются через 7 тайлов |
| Поворот | R: здание в руке; скопированный план; пустой рукой — здание под курсором; при протягивании — форма L-трассы |
| Пипетка | Q (копирует тип, поворот и настройку) |
| Выделение | ПКМ с зажатием; клик ПКМ по зданию без инструмента выделяет его |
| Снести / копировать выделенное | X или Delete / C, затем ЛКМ — вставить копию |
| Снести здание под курсором | X или Delete без выделения |
| Отмена | Клик ПКМ или Esc (снимает инструмент, выделение, выбор; без них Esc открывает меню) |
| Настройка здания | ЛКМ пустой рукой по сортировщику, разгрузчику, маршрутизатору, сборщику или мосту (фильтр и инверсия, приоритетные стороны, рецепт); мост → ЛКМ по другому мосту — связь |
| Меню строительства | ЛКМ по кнопке — взять в руку, ПКМ — скрафтить 1, Shift+ПКМ — 5; описание — в подсказке при наведении |
| Пауза / скорость | Пробел / 1, 2, 3 = ×1, ×2, ×4 |
| Исследования | J или кнопка «Исследования» в HUD: выбрать исследование кликом, «Сдать наборы» — отдать научные наборы из инвентаря (медленно); научный цех делает это быстро |
| Энергия | Постройки с электричеством (бур, сборщик, научный цех) работают в зоне опоры ЛЭП, соединённой с генератором. Зоны видны, пока в руке электрическая постройка или курсор над опорой; красная молния — нет опоры, жёлтая — не хватает мощности |
| Жидкости | Насос ставится на воду, трубы ведут к бойлеру, бойлер на угле даёт пар паровым генераторам. На воде строятся только трубы и насосы. Подземная труба: поставьте вход и выход одним поворотом (R — направление), выход развернётся сам, между ними — до 10 тайлов |
| Бур | Отдаёт добычу только с лицевой стороны (стрелка), R — поворот |
| Оверлей электросетей | P: зоны опор цветом сети, спрос и выработка, перегруженные сети мигают. Клик по опоре — окно сети с графиком |
| Лифт | Ставится на площадке шлюза или на подземном этаже, пара появляется на другом этаже; клик — направление (вниз или вверх) |
| Карта ресурсов / загрузка лент | O / L |
| Сетка | G |
| Отладка (FPS, чанки, тик, враги, поле потоков) | F3; с открытой отладкой N — вызвать следующую волну |

## Проверка из командной строки

```
set GODOT="D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe"

:: логические тесты и компиляция всех скриптов
%GODOT% --headless --path D:/Mind res://tests/test_runner.tscn

:: автопрогон со скриншотами и проверкой инструментов настоящим вводом
%GODOT% --path D:/Mind res://core/game.tscn -- --autoshot --autoshot-dir=D:/shots

:: бенчмарк симуляции лент (headless)
%GODOT% --headless --path D:/Mind res://tests/bench_conveyors.tscn

:: бенчмарк сохранений (~5000 зданий: время записи, загрузки, размер файла)
%GODOT% --headless --path D:/Mind res://tests/bench_saves.tscn

:: бенчмарк боя (1000 врагов, 80 турелей, ~5000 зданий, поле потоков 256×192)
%GODOT% --headless --path D:/Mind res://tests/bench_enemies.tscn

:: стресс-тест отрисовки
%GODOT% --path D:/Mind res://core/game.tscn -- --level=rift --stress=6000

:: пересобрать тестовые карты уровней
%GODOT% --headless --path D:/Mind --script res://tools/build_test_levels.gd
```
