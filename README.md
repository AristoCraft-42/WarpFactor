# Flowworks

Песочница про автоматизированное производство: добыча, конвейеры, переработка, логистика.
Без врагов и проигрыша — только оптимизация потоков. Godot 4.7.2, GDScript.

Архитектура и принятые решения — [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Запуск

Откройте папку в Godot 4.7.2 и нажмите F5 (главное меню).
F6 на `core/game.tscn` запускает первый уровень сразу.

## Управление (по умолчанию, переназначается в настройках)

| Действие | Клавиши |
|---|---|
| Панорама | ПКМ / СКМ с перетаскиванием, WASD / стрелки |
| Зум | Колесо (к курсору), `=` / `-` |
| Камера к ядру | H |
| Строить / линией | ЛКМ / ЛКМ с зажатием |
| Поворот | R: здание в руке; пустой рукой — здание под курсором; при протягивании — форма L-трассы |
| Пипетка | Q |
| Режим сноса | X или Delete |
| Снос рамкой | Shift + ЛКМ с перетаскиванием |
| Отмена / меню | Esc, клик ПКМ |
| Пауза / скорость | Пробел / 1, 2, 3 = ×1, ×2, ×4 |
| Настройка здания | ЛКМ пустой рукой по сортировщику, разгрузчику или мосту; мост → ЛКМ по другому мосту — связь |
| Карта ресурсов / загрузка лент | O / L |
| Сетка | G |
| Отладка (FPS, чанки) | F3 |

## Проверка из командной строки

```
set GODOT="D:\SteamLibrary\steamapps\common\Godot Engine\godot.windows.opt.tools.64.exe"

:: логические тесты и компиляция всех скриптов
%GODOT% --headless --path D:/Mind res://tests/test_runner.tscn

:: автопрогон со скриншотами и проверкой инструментов настоящим вводом
%GODOT% --path D:/Mind res://core/game.tscn -- --autoshot --autoshot-dir=D:/shots

:: бенчмарк симуляции лент (headless)
%GODOT% --headless --path D:/Mind res://tests/bench_conveyors.tscn

:: стресс-тест отрисовки
%GODOT% --path D:/Mind res://core/game.tscn -- --level=rift --stress=6000

:: пересобрать тестовые карты уровней
%GODOT% --headless --path D:/Mind --script res://tools/build_test_levels.gd
```
