# Спрайты зданий

Сюда кладутся нарисованные спрайты: `<id здания>.png`, например `furnace.png`, `assembler.png`.
Id берётся из `docs/CONTENT.md` (столбец с id) или из имени файла в `buildings/defs/`.

## Формат

**Одна картинка на здание — полоса из трёх квадратных кадров в ряд:**

| кадр | состояние | когда показывается |
|---|---|---|
| 1-й (слева) | работает | здание делает своё дело |
| 2-й | простаивает | всё есть, но выход забит (или цели нет — у турели) |
| 3-й | выключено | нет топлива, электричества, сырья, патронов или рецепта |

Сторона кадра — `размер здания × 32` пикселя:

| размер | кадр | вся полоса |
|---|---|---|
| 1×1 | 32×32 | 96×32 |
| 2×2 | 64×64 | 192×64 |
| 3×3 | 96×96 | 288×96 |
| 4×4 | 128×128 | 384×128 |

Кадров может быть меньше трёх: недостающие берутся из первого. Один кадр — здание всегда
выглядит одинаково (так было до появления состояний).

Пример правильной полосы — `_sample_states.png` (подчёркивание в начале означает, что это
образец, а не здание: такого id нет, и в игру файл не попадает).

## Как экспортировать из Aseprite

1. Три кадра в таймлайне: первый — работа, второй — простой, третий — выключено.
2. `File → Export Sprite Sheet`.
3. **Sheet type:** `Horizontal Strip`; **Padding** — выключить; **Trim** — выключить.
4. **Layers:** `Merged`; **Frames:** `All frames`.
5. Сохранить как `art/buildings/<id>.png` (Output File), `JSON Data` не нужен.

Не GIF: он теряет полупрозрачность и палитру. Не отдельные файлы на состояние и не слои —
движок читает только готовую картинку, а полосу удобнее держать одним файлом.

## После добавления файла

```
python tools/data/make_content.py
godot --headless --path D:\Mind --import
```

Первая команда пропишет спрайт в описание здания (`buildings/defs/<id>.tres`), вторая — вгонит
картинку в проект. Дальше игра сама собирает все кадры в общий атлас: рисовать здания одной
текстурой дешевле, чем каждое своей.

Фильтрация в проекте — «ближайший сосед» (`default_texture_filter=0`), так что пиксели
остаются пикселями, а размер кадра лучше делать ровно таким, как в таблице: картинку другого
размера движок растянет.
